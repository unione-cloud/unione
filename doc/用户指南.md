# 用户指南

## 1. 统一门户功能

### 1.1 用户登录

**功能说明**：用户登录系统的入口

**操作步骤**：
1. 访问系统登录页面
2. 输入用户名和密码
3. 根据配置可能需要输入验证码或进行二次验证
4. 点击登录按钮

**注意事项**：
- 默认管理员账号：admin/admin123
- 首次登录请及时修改密码

### 1.2 个人中心

**功能说明**：管理用户个人信息

**主要功能**：
- 查看个人基本信息
- 修改密码
- 绑定/解绑手机号和邮箱
- 设置登录安全选项

**密码修改步骤**：
1. 进入个人中心
2. 点击「修改密码」
3. 输入原密码和新密码
4. 确认修改

### 1.3 样式设置

**功能说明**：自定义系统界面风格

**可设置项**：
- 主题切换：亮色/暗色主题
- 语言设置：支持多语言切换
- 布局设置：菜单布局方式
- 字体大小：界面字体大小调整

### 1.4 站内信
**功能说明**：管理用户站内信

**主要功能**：
- 查看站内信列表
- 点击站内信查看详情
- 标记已读/删除站内信

### 1.4 系统集成
**功能说明**：完成系统与其他服务的集成配置

**主要功能**：
- 菜单集成
- 页面集成
- 第三方系统集成


## 2. 系统管理功能

### 2.1 基础管理

#### 2.1.1 应用管理

**功能说明**：管理系统中的应用信息

**操作步骤**：
1. 进入「系统管理」>「基础管理」>「应用管理」
2. 点击「新增」创建应用
3. 填写应用名称、应用标识、应用描述等信息
4. 设置应用状态和权限
5. 保存应用信息

#### 2.1.2 菜单管理

**功能说明**：配置系统菜单结构

**操作步骤**：
1. 进入「系统管理」>「基础管理」>「应用管理」>「资源管理」
2. 点击「新增」创建菜单项
3. 填写菜单名称、图标、路由地址等信息
4. 设置父级菜单和排序
5. 配置菜单权限标识

#### 2.1.3 按钮管理

**功能说明**：管理页面按钮及其权限

**操作步骤**：
1. 进入「系统管理」>「基础管理」>「应用管理」>「资源管理」
2. 点击「新增」创建按钮
3. 选择所属菜单
4. 设置按钮名称、图标、权限标识等

#### 2.1.4 字典管理

**功能说明**：管理系统中的字典数据

**操作步骤**：
1. 进入「系统管理」>「基础管理」>「字典管理」
2. 点击「新增」创建字典项
3. 填写字典名称、编码、描述等信息
4. 设置字典项值和排序
5. 保存字典项信息



### 2.2 组织管理

#### 2.2.1 机构管理

**功能说明**：管理企业组织架构

**操作步骤**：
1. 进入「系统管理」>「组织管理」>「机构管理」
2. 点击「新增」创建机构节点
3. 设置机构名称、简称、负责人等信息
4. 保存机构信息

#### 2.2.2 用户管理

**功能说明**：管理系统用户

**操作步骤**：
1. 进入「系统管理」>「组织管理」>「用户管理」
2. 点击「新增」创建用户
3. 填写用户基本信息
4. 分配用户所属机构和角色
5. 设置用户状态

**批量操作**：
- 批量导入：通过Excel导入用户
- 批量导出：导出用户数据
- 批量禁用/启用：管理用户状态

#### 2.2.3 角色管理

**功能说明**：定义和管理系统角色

**操作步骤**：
1. 进入「系统管理」>「组织管理」>「角色管理」
2. 点击「新增」创建角色
3. 填写角色名称和描述
4. 为角色分配权限

### 2.3 权限管理

**功能说明**：管理系统权限资源，用户权限，用户角色权限，角色权限

**权限类型**：
- 菜单权限：控制菜单的可见性
- 按钮权限：控制按钮的可操作性
- 数据权限：控制数据的访问范围

**操作步骤**：
1. 进入「系统管理」>「权限管理」
2. 选择用户或角色
3. 分配相应的权限资源
4. 保存权限配置

## 3. 统一消息功能

### 3.1 消息类型管理

**功能说明**：定义系统中的消息类型

**操作步骤**：
1. 进入「系统管理」>「统一消息」>「消息类型管理」
2. 点击「新增」创建消息类型
3. 设置类型名称、编码和描述

### 3.2 消息模板管理

**功能说明**：创建和管理消息模板

**操作步骤**：
1. 进入「系统管理」>「统一消息」>「消息模板管理」
2. 点击「新增」创建消息模板
3. 选择消息类型
4. 设置模板标题和内容
5. 配置模板参数

### 3.3 消息发送

**操作步骤**：
1. 进入「系统管理」>「统一消息」>「消息管理」

4. 设置消息优先级
5. 点击发送

### 3.4 我的消息 

**功能说明**：查看和管理用户接收到的消息

**操作步骤**：
1. 进入「系统管理」>「统一消息」>「我的消息」
2. 查看消息列表
3. 点击消息查看详情
4. 可进行标记已读、删除等操作

## 6. 常见问题解答

### 6.1 登录问题

- 密码错误：确认输入的密码是否正确，注意区分大小写
- 账号锁定：连续输入错误密码过多，账号会被临时锁定
- 验证码问题：验证码区分大小写，有效期为几分钟

### 6.2 权限问题

- 无操作权限：联系管理员分配相应权限
- 看不到某些菜单：可能是未分配该菜单的权限

### 6.3 性能问题

- 系统响应慢：检查服务器资源使用情况，优化数据库查询
- 页面加载慢：清理浏览器缓存，检查网络连接
