# 开发准备

## 1. 开发环境准备

### 1.1 环境要求

- **JDK**: JDK 21+
- **开发工具**: IntelliJ IDEA Vs Code 或 TRAE(推荐)
- **构建工具**: Maven 3.6+
- **数据库**: MySQL 5.7+ 或 MySQL 8.0
- **缓存**: Redis 5.0+
- **版本控制**: Git

### 1.2 项目导入

1. 克隆代码库
   _github_：
   ```bash
   git clone https://github.com/unione-cloud/unione.git
   cd unione
   ```
   _gitee_：
   ```bash
   git clone https://gitee.com/unione-cloud/unione.git
   cd unione
   ```

2. 导入到 IDE
   - **IntelliJ IDEA**: 选择 Import Project -> 选择 pom.xml
   - **Vs Code**: 选择 File -> Open Folder -> 选择 unione 目录
   - **TRAE**: 选择 File -> Open -> 选择 unione 目录

3. 安装依赖
```bash
mvn clean install -DskipTests
```

## 2. 项目结构说明

### 2.1 模块说明

| 模块名称 | 主要职责 | 所在目录 |
|---------|---------|--------|
| unione-core | 核心功能模块，包含基础定义和通用接口 | unione-core/ |
| unione-gateway | API网关，请求路由与鉴权 | unione-gateway/ |
| unione-portal | 门户服务，用户界面入口 | unione-portal/ |
| unione-job | 任务调度模块 | unione-job/ |
| unione-beetsql | 数据访问增强模块 | unione-beetsql/ |
| unione-codegen | 代码生成模块 | unione-codegen/ |
| unione-util | 工具类库 | unione-util/ |
| unione-web | Web应用模块 | unione-web/ |
| unione-starter | 启动器模块 | unione-starter/ |

### 2.2 代码规范

- 遵循 Java 编码规范
- 类、方法、变量命名遵循驼峰命名法
- 方法和类添加适当的注释
- 每个方法应该有清晰的职责
