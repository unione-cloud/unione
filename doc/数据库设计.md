# 数据库设计

## 1. 数据库概述

UniOne Cloud 使用 MySQL 作为主要数据库，采用关系型数据库设计。数据库名为 `unione`，字符集使用 `utf8mb4`，排序规则使用 `utf8mb4_unicode_ci`。

## 2. 数据库初始化

系统提供了初始化SQL脚本，位于 `db/mysql/unione-init.sql`，包含了所有必要的表结构和初始数据。

执行初始化脚本：
```sql
CREATE DATABASE unione DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE unione;
SOURCE db/mysql/unione-init.sql;
```

## 5. 索引设计

为提升查询性能，在以下字段上建立了索引：

- `sys_user.username`：唯一索引，加速用户登录验证
- `sys_user.mobile`：普通索引，加速手机号查询
- `sys_user.email`：普通索引，加速邮箱查询
- `sys_role.code`：唯一索引，加速角色编码查询
- `sys_menu.permission`：普通索引，加速权限检查
- `sys_user_role.user_id` 和 `sys_user_role.role_id`：复合索引，加速用户角色查询
- `sys_role_menu.role_id` 和 `sys_role_menu.menu_id`：复合索引，加速角色权限查询
- `sys_operation_log.user_id` 和 `sys_operation_log.create_time`：复合索引，加速日志查询
- `sys_user_message.user_id` 和 `sys_user_message.read_status`：复合索引，加速用户消息查询

## 6. 数据安全

### 6.1 密码安全

- 用户密码使用BCrypt算法加密存储，不可逆
- 密码加密强度可配置
- 登录失败次数限制，防止暴力破解

### 6.2 敏感数据处理

- 敏感字段（如手机号、邮箱）在日志中脱敏显示
- 敏感数据查询权限控制
- 定期数据备份策略

### 6.3 数据审计

- 关键操作记录操作日志
- 数据变更记录审计日志
- 支持数据变更回滚功能
