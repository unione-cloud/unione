# unione 数据库设计

## 1. 数据库概述

- 数据库类型：MySQL
- 数据库名称：unione
- 字符集：utf8mb4
- 排序规则：utf8mb4_bin

## 2. 初始化说明

数据库初始化通过 `unione-init.sql` 脚本执行，该脚本包含了所有表的创建语句和初始数据。

## 5. 索引设计

为提升查询性能，在以下字段上建立了索引：

- `sys_user.USER_ACCOUNT`：唯一索引，加速用户登录验证
- `sys_user.MOBILE`：普通索引，加速手机号查询
- `sys_user.EMAIL`：普通索引，加速邮箱查询
- `sys_role.ROLE_CODE`：唯一索引，加速角色编码查询
- `sys_user_role.USER_ID` 和 `sys_user_role.ROLE_ID`：复合索引，加速用户角色查询
- `sys_role_permis.ROLE_ID` 和 `sys_role_permis.APP_ID` 和 `sys_role_permis.RES_ID`：复合索引，加速角色权限查询
- `sys_user_permis.USER_ID` 和 `sys_user_permis.APP_ID` 和 `sys_user_permis.RES_ID`：复合索引，加速用户权限查询
- `sys_logs.USER_ID` 和 `sys_logs.CREATED`：复合索引，加速日志查询
- `sys_logs.TENANT_ID` 和 `sys_logs.CREATED`：复合索引，加速租户日志查询
- `sys_organ_permis.ORG_ID` 和 `sys_organ_permis.APP_ID` 和 `sys_organ_permis.RES_ID`：复合索引，加速机构权限查询

## 6. 数据安全

### 6.1 密码安全

- 用户密码使用加密算法存储，不可逆
- 密码复杂度要求
- 登录失败次数限制，防止暴力破解

### 6.2 敏感数据处理

- 敏感字段（如手机号、邮箱）在日志中脱敏显示
- 敏感数据查询权限控制
- 定期数据备份策略

### 6.3 数据审计

- 关键操作记录在sys_logs表中
- 数据变更记录详细的操作内容和状态
- 支持操作日志查询和分析
