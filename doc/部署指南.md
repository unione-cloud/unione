# 部署指南

## 1. 环境准备

### 1.1 服务器要求

- **操作系统**：Linux（推荐Debian 10/11、CentOS 7/8、Ubuntu 18.04/20.04）或Windows Server
- **CPU**：至少2核，推荐4核或更高
- **内存**：至少8GB，推荐16GB或更高
- **磁盘**：至少100GB SSD，推荐500GB SSD
- **网络**：稳定的网络连接，确保服务之间可以正常通信

### 1.2 依赖软件

- **JDK**：JDK 21+
- **MySQL**：5.7+ 或 8.0
- **Redis**：5.0+
- **Docker**（推荐）：20.10+
- **Docker Swarm**（推荐）：用于集群部署

## 2. 手动部署

### 2.1 准备工作

1. 安装必要的软件
   - JDK
   - MySQL
   - Redis

2. 创建数据库
   ```sql
   CREATE DATABASE unione DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. 导入初始化数据
   ```bash
   mysql -u root -p unione < db/mysql/unione-init.sql
   ```

### 2.2 配置服务

1. 编译打包项目
   ```bash
   mvn clean package -DskipTests
   ```

2. 修改配置文件
   编辑各服务的`bootstrap-*.yml`文件，配置数据库连接、Redis连接等信息。

3. 启动服务
   按照依赖顺序启动各服务：
   ```bash
   java -jar unione-starter.jar
   java -jar unione-demo.jar
   # 其他服务以此类推
   ```

## 3. Docker部署

### 3.1 环境准备

1. 安装Docker
   - 参考[Docker官方文档](https://docs.docker.com/get-docker/)

2. 安装Docker Compose（可选）
   - 用于本地开发和测试环境

3. 配置Docker Swarm（推荐）
   - 用于生产环境集群部署
   ```bash
   docker swarm init
   ```

### 3.2 构建Docker镜像

1. 使用项目提供的Dockerfile构建镜像
   ```bash
   docker build -t unione/unione-starter .
   # 为其他服务构建镜像
   ```

2. 或使用提供的打包脚本
   ```bash
   # Windows环境：开发环境，无自动化构建环境下，通过批处理脚本打包并构建Docker镜像然后自动部署
   package.bat
   ```

### 3.3 使用Docker Compose部署

1. 创建`docker-compose.yml`文件（可参考项目中的`docker-stack.yml`）

2. 启动服务
   ```bash
   docker-compose up -d
   ```

### 3.4 使用Docker Swarm部署

1. 使用提供的`docker-stack.yml`文件

2. 部署应用栈
   ```bash
   docker stack deploy -c docker-stack.yml unione
   ```

3. 查看服务状态
   ```bash
   docker stack services unione
   ```

## 4. 环境配置

### 4.1 数据库配置

在各服务的`application.yml`中配置MySQL连接：

```yaml
spring:
  datasource:
    url: jdbc:mysql://mysql:3306/unione?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: yourpassword
    driver-class-name: com.mysql.cj.jdbc.Driver
```

### 4.2 Redis配置

```yaml
spring:
  redis:
    host: redis
    port: 6379
    password:
    database: 0
```

### 4.3 服务注册发现配置

```yaml
spring:
  cloud:
    nacos:
      discovery:
        server-addr: nacos:8848
```

### 4.4 网关配置

```yaml
spring:
  cloud:
    gateway:
      routes:
        - id: unione-portal
          uri: lb://unione-portal
          predicates:
            - Path=/api/portal/**
          filters:
            - StripPrefix=1
```

## 5. 高可用部署

### 5.1 数据库高可用

- 配置MySQL主从复制
- 或使用MySQL集群解决方案（如MySQL Group Replication）

### 5.2 服务高可用

- 部署多个服务实例
- 配置负载均衡
- 启用服务熔断和降级

### 5.3 缓存高可用

- 配置Redis主从复制
- 使用Redis Sentinel或Redis Cluster

## 6. 监控与维护

### 6.1 健康检查

访问各服务的健康检查端点：
```
http://服务地址:端口/actuator/health
```

### 7.2 日志管理

- 查看Docker容器日志：
  ```bash
  docker logs [container-id]
  ```
- 配置日志收集（可选）：使用ELK等日志收集方案

### 7.3 性能监控

- 使用Spring Boot Actuator收集指标
- 集成Prometheus和Grafana进行监控

## 8. 安全加固

### 8.1 数据库安全

- 修改默认密码
- 限制数据库访问IP
- 定期备份数据

### 8.2 服务安全

- 设置合适的JVM参数
- 配置HTTPS
- 限制服务访问端口

### 8.3 网络安全

- 配置防火墙规则
- 使用网络隔离
- 定期进行安全扫描

## 9. 常见问题排查

### 9.1 服务启动失败

- 检查端口是否被占用
- 检查数据库连接是否正常
- 查看服务日志定位错误原因

### 9.2 服务访问超时

- 检查网络连接
- 检查服务负载
- 优化数据库查询

### 9.3 数据不一致

- 检查事务配置
- 检查缓存更新机制
- 查看数据库日志

## 10. 版本更新

### 10.1 备份

在更新前备份：
- 数据库数据
- 配置文件
- 自定义代码修改

### 10.2 更新步骤

1. 停止旧版本服务
2. 更新应用程序
3. 执行数据库迁移脚本（如有）
4. 启动新版本服务
5. 验证系统功能

### 10.3 回滚方案

1. 停止新版本服务
2. 恢复旧版本应用程序
3. 恢复数据库备份
4. 启动旧版本服务
